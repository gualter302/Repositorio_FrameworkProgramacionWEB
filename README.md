# Repositorio - Framework de Programación Web

| Carpeta | Contenido |
|---|---|
| `Taller1y2_Entorno_y_API_Pokemon/` | Creación del entorno React + consumo de una API externa (PokeAPI): Pokédex |
| `Taller3_Sidebar/` | Sidebar colapsable (`isCollapsed`, 80px), iconos, botón Toggle en el Navbar y diseño responsivo |
| `Taller4_Conexion_Backend_Frontend/` | Conexión del frontend React (Taller 3) con el backend en Go (Fiber): login y catálogo desde la API |
| `Taller5_Fase1_Arquitectura_API_Robusta/` | Copia del Taller 4 con respuestas de error uniformes, validaciones, consulta de producto por ID y verificación del servidor |
| `Taller5_Leccion_Catalogo_Multinivel/` | Lección Tema 5: roles admin/cliente, tienda a pantalla completa, catálogo con filtros, detalle con lightbox, carrito persistente, checkout, red multinivel y dashboard |
| `Unidad2_Fase2_Persistencia_PostgreSQL/` | Fase 1 más almacenamiento de usuarios, productos y red en PostgreSQL |
| `Unidad2_Fase3_Cache_Redis/` | Fases 1 y 2 más caché del catálogo y la red con Redis |
| `Unidad2_Fase4_Checkout_Concurrencia/` | Fases 1, 2 y 3 más checkout transaccional, stock y comisiones concurrentes |
| `Taller7_Registro_Referidos/` | Fase 4 más registro con código de invitación, bcrypt, JWT y red propia |

Cada carpeta tiene su propio `README.md` con las instrucciones para ejecutarla.

El taller acumulativo más reciente es `Taller8_PWA/`: instalación, catálogo sin conexión,
carrito por usuario y compras con reintentos seguros. Su README incluye pruebas y despliegue HTTPS.

## Taller 6 - Ahorro de tokens

Este taller agrega archivos de orientación en la raíz para encontrar rápidamente el código,
conocer el avance real y evitar lecturas innecesarias:

- `PROJECT_MAP.md`: mapa compacto de carpetas y archivos importantes.
- `REQUIREMENTS_CHECKLIST.md`: requisitos terminados y pendientes.
- `ANALISIS_FUNCIONAL_U2.md`: brechas de negocio que faltan después del Taller 7.
- `PLAN_IMPLEMENTACION_U2.md`: orden propuesto para los siguientes talleres.
- `AGENTS.md`: instrucciones que Codex carga automáticamente al trabajar en el repositorio.
- `CODEX_SETUP.md`: pasos opcionales para agregar Playwright y memoria a Codex.
